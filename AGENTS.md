# AIProgramming Asset Library — agent rules

- This repository is the approved asset registry for AIProgramming Godot/Web projects.
- Prefer assets from `catalog/sources.json` and generated catalog files.
- Do not add arbitrary internet assets without an explicit license review.
- Keep third-party provenance and license metadata.
- Runtime target is Godot 4.x Web; prefer GLB/glTF, PNG/WebP/JPG, OGG/WAV, TTF/OTF.
- Never commit generated `dist/`, downloaded caches or extracted vendor binaries to normal Git history.
- Student projects should reference packs via `assets.json`; downloading happens during sync/build.
- Keep visual packs internally coherent; do not mix unrelated visual styles unless explicitly requested.
- For 3D Kenney packs, prefer GLB over FBX/OBJ/DAE/STL to avoid duplicate source formats.
